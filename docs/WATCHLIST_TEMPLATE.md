## 一、结论先说

### 可以从这份 xlsx 启动，但不能整份直接拿来做 watchlist

这份表格对你非常有价值，因为它证明了：

- `vape wholesale usa discount code` 这个词确实能拉出一批 coupon-intent 来源
- 市场上已经存在一批会持续覆盖这个 merchant 的聚合页
- 你现在可以直接从里面筛出第一批 watchlist 种子来源

但它的问题也很明显：

- 有不少低质量聚合站
- 有明显地域错配和镜像页
- 有与真实 coupon 价值无关的噪音结果
- 有些域名只是在 SERP 里出现，不代表值得长期跟踪

所以正确做法不是“整表拿来用”，而是“从表里筛种子来源，再建立自己的固定 watchlist”。

## 六、后续怎么发现新的高质量来源

### 方法 1：同 merchant，扩更多关键词

不要只盯一个词，建议围绕同一个 merchant 扩这些关键词：

- `vape wholesale usa coupon code`
- `vape wholesale usa promo code`
- `vape wholesale usa free shipping`
- `vape wholesale usa rewards`
- `vape wholesale usa clearance`
- `vapewholesaleusa discount`

**目的：**

- 找到不同意图下稳定出现的来源站
- 判断哪些域名会跨关键词重复出现

### 方法 2：同一类 merchant 横向扩展

拿 3-5 个核心 merchant 做相同搜索，然后找重复出现的域名：

- `the vape mall discount code`
- `flawless vape shop coupon code`
- `geek vape coupon code`
- `vapesourcing coupon code`
- `discount vape pen coupon codes`

**目的：**

- 如果某个域名不仅覆盖 `Vape Wholesale USA`，还稳定覆盖其他核心商家，它才更值得进入长期 watchlist

### 方法 3：用交集，而不是用单次排名

高质量来源不是“某次排第 1”，而是：

- 在多个 merchant 里重复出现
- 在多个关键词里重复出现
- 页面内容结构稳定
- 有明确的 merchant page
- 折扣信息相对具体

## 七、筛选高质量来源的标准

### 可以纳入 watchlist 的来源，至少满足 3 条

- 多次出现在你目标关键词 SERP
- 明确覆盖你的核心 merchant
- 页面结构稳定，不是随机生成页
- 会更新 offer，而不是只有静态模板
- 对 code / discount / expiry / restrictions 有较明确描述

### 不要纳入的来源

- 地域错配太强
- 泛模板页太多
- 大量镜像页
- 页面看起来像自动拼装 SEO 垃圾页
- 信息极其模糊，只写 “up to X% off”

## 九、连续跑 2-3 周怎么做

### 先说目标

这 `2-3` 周不是为了“马上找到很多新 code”，而是为了回答 4 个问题：

1. 哪些来源站真的每周都有增量？
2. 哪些来源站只是噪音或重复信息？
3. 哪些来源最适合做 `sourceCount` 的交叉确认？
4. 你的每周维护时间到底会被什么步骤吃掉？

### Week 0：准备阶段（只做一次）

先准备一个表格，推荐就按下面字段建在 Google Sheets / Excel：

| Week | Merchant | Source Domain | Source URL | Checked At | Changed? | Candidate Code | Candidate Offer | Same As Existing? | Action | Confidence | Notes |
|------|----------|---------------|------------|------------|----------|----------------|-----------------|-------------------|--------|------------|-------|

**Action** 建议固定这几个值：

- `ignore`
- `compare`
- `verify`
- `add_to_offers`
- `mark_expired`
- `keep_watching`

### Week 1：建立基线

**目标：**

- 不急着大量改数据
- 先把 8 个来源都看一遍
- 建立“本周之前，现有数据长什么样”的基线

**具体做法：**

1. 打开 [offers.ts](file:///Users/dezuo/Documents/Codex/2026-05-21/vape-wholesale-usa-discount-code/lib/offers.ts)
2. 找出当前 `Vape Wholesale USA` 已有的 offer
3. 依次打开这 8 个来源
4. 每看一个来源，只做 3 件事：
- 有没有新 code / 新折扣描述
- 有没有已存在 offer 的变化
- 有没有明显失效或冲突信息
5. 把所有观察结果写进表格

**Week 1 不建议做的事：**

- 不要一次性改很多商家
- 不要急着把每个来源都写进 `offers.ts`
- 不要因为一个来源写了新 code 就直接上线

**Week 1 输出物：**

- 一份完整的 baseline 表
- 1-3 条值得继续验证的 candidate
- 1 份“哪些来源看起来质量更高”的初步印象

### Week 2：做变化识别

**目标：**

- 判断哪些来源“连续两周都有信息价值”
- 把 Week 1 的 candidate 拿去做人工验证

**具体做法：**

1. 还是按同样顺序看 8 个来源
2. 每个来源重点看：
- 页面内容有没有变
- code 是否新增 / 消失
- discount 描述是否有变化
- 和你当前站内 offer 是否冲突
3. 对 Week 1 进入 `verify` 的项，去 cart / checkout 验证
4. 对验证失败的项做记录，不急着删除来源站，只先记为低质量

**Week 2 结束时要做一个小评分：**

给每个来源站打一个简单分数：

- `+2`：本周发现了有用的新线索
- `+1`：可用于 cross-reference
- `0`：本周没新增但可保留观察
- `-1`：重复内容很多
- `-2`：明显噪音、错配、低可信

### Week 3：做清单收缩

**目标：**

- 不再平均对待 8 个来源
- 开始收缩成真正高价值的固定 watchlist

**具体做法：**

1. 回看前两周的记录
2. 把 8 个来源分成 3 类：
- `核心保留`
- `继续观察`
- `准备淘汰`
3. 只把“核心保留”的来源继续作为下周固定输入
4. 对“继续观察”的来源，不再每周都看，可以改为双周
5. 对“准备淘汰”的来源，移出主清单

**3 周后你应该得到的结果：**

- 一个真正可执行的核心 watchlist
- 1 套你自己的判断标准
- 1 份更可靠的候选来源池

## 十、每周一次具体怎么操作

### 建议每周固定一个 45-60 分钟窗口

比如周一上午或周二下午，按同一顺序做：

1. 打开当前 merchant 的 [offers.ts](file:///Users/dezuo/Documents/Codex/2026-05-21/vape-wholesale-usa-discount-code/lib/offers.ts)
2. 打开 watchlist 的 8 个来源页
3. 一页一页记录变化
4. 标出需要 `verify` 的项
5. 最后统一去 checkout 验证最值得测的 1-3 条

### 每次看一个来源时，固定问自己 5 个问题

1. 这个来源本周有没有新信息？
2. 这条信息和现有 offer 是同一条还是新的一条？
3. 它能不能帮助提高 `sourceCount`？
4. 它是更像 `reported`、`official`，还是明显不可信？
5. 它值不值得我花时间去 checkout 验证？

### 每周结束时只做一个决策

不是“这周更新了多少 code”，而是：

- 下周我还要不要继续看这个来源？

如果连续 2-3 周都没价值，就该降级或淘汰。

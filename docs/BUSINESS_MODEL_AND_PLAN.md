## 一、项目定位：我们到底是什么？

**一句话定义：**

> 一间面向美国电子烟批发采购者的**省钱情报站**——不碰货、不发货、不管售后，只提供**可信的折扣信息、采购决策工具和 B2B 供需连接**。

**类比理解：**
- 你不是亚马逊（不卖货）
- 你不是普通 coupon 站（不堆假码）
- 你是 **"批发采购领域的 Wirecutter + 垂直行业的 Slickdeals"**

**核心服务：**
1. **折扣情报** —— 聚合、验证、分级展示 wholesale vape discount codes
2. **决策工具** —— 批发计算器、free shipping 门槛对比、buyer checklist
3. **供需连接** —— newsletter 沉淀买家，Quote Match 表单撮合采购需求

## 二、用户能获得什么？（Value Proposition）

### 对终端用户（美国烟店老板 / 批发商）

| 痛点 | 我们的解决方案 |
|---|---|
| 搜 10 个 coupon 站，code 都是 "Click to Reveal"，点完发现不能用 | **可信分级表格**：official / reported / verified 三级标注，来源 URL 透明可追溯 |
| 算不清批发折扣真实价值（运费、州税、minimum order 变量多） | **批发省钱计算器**：输入订单额、折扣、运费，即时算真实 checkout total |
| 不知道哪家 free shipping 门槛低 | **专门对比页**：Vape Wholesale USA $3,000+ vs Flawless $100+ vs Geek Vape $99+ 一目了然 |
| 怕踩坑买到过期码 / 假码 | **Last checked 日期 + 验证日志**：标注每条 offer 的最后核实时间 |
| 找不到真正的大宗采购渠道 | **Quote Match 表单**：提交采购需求，对接经过筛选的 wholesale partners |

### 对用户的核心承诺

> **"我们不卖电子烟，我们只帮你买得更便宜、更透明、更合规。"**

## 三、站长能获得什么？（Business Model）

### 收入层（变现路径，按优先级排序）

#### Phase 1：流量期（0-3 个月）—— 无直接收入，积累资产
- **目标**：SEO 收录、自然流量、邮件订阅、验证数据
- **动作**：上线、抢词、内容发布、code 验证

#### Phase 2：Affiliate 期（3-6 个月）—— 轻量变现
- **Merchant outbound click**：用户点击商家链接购买，你拿佣金（ShareASale、CJ、Direct affiliate）
- **Newsletter 插入 affiliate code**：邮件推送里放 tracking link
- **预期收入**：$100-500/月（取决于流量规模）

#### Phase 3：赞助期（6-12 个月）—— 稳定现金流
- **Sponsored placement**：商家付费在表格/邮件中获得 top 推荐位
- **Newsletter 广告位**：每周 newsletter 中插入 1-2 条 sponsored deals
- **预期收入**：$500-2,000/月

#### Phase 4：B2B 线索期（12 个月+）—— 高价值变现
- **Qualified lead intro**：Quote Match 表单收集的采购需求，按条或按成交分成卖给供应商
- **目标买家**：中国深圳/东莞电子烟工厂、美国本土 distributor
- **预期收入**：$2,000-10,000/月（取决于线索质量和成交量）

### 资产层（越积累越值钱）

| 资产 | 为什么值钱 | 现在状态 |
|---|---|---|
| **验证数据库** | 独家 checkout 验证记录，别人没有 | 空白，需建设 |
| **邮件列表** | 完全控制的私有流量，算法无关 | 空白，需建设 |
| **B2B 买家池** | 真实的采购需求、州分布、品类偏好 | 空白，需建设 |
| **商家关系** | 独家 code、提前促销通知、sponsored 合作 | 空白，需建设 |
| **SEO 内容资产** | 长尾页面、行业报告、FAQ = 持续自然流量 | 骨架完成，需填充 |

## 四、核心竞争力与壁垒（Moat Strategy）

### 壁垒金字塔

```
        ┌─────────────────────────────┐
        │    商家独家关系 + B2B 网络    │  ← 最高壁垒，时间积累
        ├─────────────────────────────┤
        │    独家数据资产（验证日志）   │  ← 信任壁垒，人力投入
        ├─────────────────────────────┤
        │    深度内容（行业报告/分析）  │  ← 搜索壁垒，创作投入
        ├─────────────────────────────┤
        │    社区信任 + 邮件资产        │  ← 品牌壁垒，运营投入
        ├─────────────────────────────┤
        │    基础信息聚合（现有水平）   │  ← 无壁垒，一周可复制
        └─────────────────────────────┘
```

### 四层壁垒详解

#### 1. 数据壁垒（最优先建设）

**现状：** 29 条 offer，大部分是 reported（第三方说的，未验证）

**目标状态：**
- 每条 code 都有 **checkout 验证记录**（成功/失败、实际折扣额、restriction）
- 独家 negotiated codes（和商家谈的 "只在我们的站上有的 code"）
- 历史数据库（哪些 code 季节性复活、哪些商家在 Q4 最大方）

**执行：**
- 每周验证 5-10 个热门 code（手动或自动化 Playwright）
- 每月联系 3-5 家商家要 exclusive code / affiliate 合作

#### 2. 关系壁垒（长期最值钱）

**商家侧演进路径：**

| 时间 | 你提供 | 商家回馈 |
|---|---|---|
| 现在 | 免费曝光（放在表格里） | 公开信息 |
| 3 个月 | 邮件推送 + 内容推荐 | 独家 code / 提前促销通知 |
| 6 个月 | 赞助位（Top 3 推荐） | 赞助费 / CPA 佣金 |
| 12 个月 | B2B 线索转介 | 分成 / 更高佣金 |

**买家侧：**
- Quote Match 表单 → 积累采购需求数据库（州、采购量、品类、license 状态）
- 未来可对接给供应商，按 lead 或成交收费

#### 3. 内容壁垒（搜索流量的护城河）

**别人懒得做、你做了就能垄断长尾词的内容：**
- 各州 vape 消费税对比 + 真实成本计算
- 品牌级 wholesale 利润分析（如 Geek Bar Pulse 15K 零售毛利 80-140%）
- 季度行业折扣趋势报告
- PACT Act / FDA 合规采购指南

**原则：** 从 "coupon 列表站" 升级为 "批发采购情报站"。

#### 4. 社区与品牌壁垒（终极护城河）

**核心指标：用户是否会说 "去 Vape Wholesale Discount Tracker 查一下，他们最靠谱"**

建设方法：
- **Transparency first**：每周 newsletter 公开 "这周测试了 6 个 code，3 个能用、2 个过期"
- **用户验证网络**：用户提交 code → 你验证 → 公开致谢 → 形成正向循环
- **邮件粘性**：不是 spam，是 "帮我省钱的工具"，退订率会极低

## 六、风险与合规边界

### 必须永远遵守的红线

1. **年龄门槛**：全站 21+ 声明，不面向未成年人
2. **不承诺合法性**：只提供信息，不声称某商品在某州一定合法
3. **不碰健康宣称**：绝不提 "戒烟"、"健康"、"安全"
4. **不堆假码**：reported 的明确标注，verified 的必须有 checkout 证据
5. **CAN-SPAM 合规**：邮件必须有退订链接、真实发件地址、不误导标题
6. **Affiliate 披露**：所有赞助/佣金关系必须明确标注

### 风险对冲

- **Google 算法变动**：邮件列表是私有资产，不受算法影响
- **商家政策变动**：不押单一商家，分散在 8+ 个 merchant
- **法规变动**：PACT Act / FDA 政策变化时，及时更新 compliance 页面
